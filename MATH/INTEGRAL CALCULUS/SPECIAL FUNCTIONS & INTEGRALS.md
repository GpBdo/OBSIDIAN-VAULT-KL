# SPECIAL FUNCTIONS
## Gamma function $\Gamma(x)$
$$\Gamma(z)=\int^\infty_0e^{-t}t^{z-1}\,\mathrm dt$$
$$\text{Dom}(\Gamma)=\lbrace z\in\mathbb C\mid z\notin\lbrace0,-1,-2,\ldots\rbrace\rbrace$$
**Properties:**
- $\Gamma(n+1)=n!$
- $\Gamma (z+1)=z\,\Gamma(z)$
- $\Gamma(z)\,\Gamma(1-z)=\dfrac{\pi}{\sin(\pi z)}$
- $\Gamma\left(\dfrac{1}{2}\right)=\sqrt{\pi}$
# SPECIAL INTEGRALS
## Fresnel Integrals
$$S(x)=\int^x_0\sin(t^2)\,\mathrm dt$$
$$C(x)=\int^x_0\cos(t^2)\,\mathrm dt$$
$$\int^\infty_0\sin(t^2)\,\mathrm dt=\int^\infty_0\cos(t^2)\,\mathrm dt=\sqrt{\frac{\pi}{8}}$$
